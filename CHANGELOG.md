# Changelog

All notable changes to Scripture Scroller are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## Unreleased

- Added comprehensive architecture, maintenance, testing, release, marketplace, and troubleshooting documentation.

## 1.0.0 - 2026-08-23

### Added

- Offline Omarchy bar widget containing 100 encouraging Berean Standard Bible passages.
- A 30-second default rotation interval with configurable interval, width, scroll speed, and hover behavior.
- A nonrepeating shuffled cycle that prevents the final passage of one cycle from immediately repeating at the start of the next.
- Horizontal marquee presentation and a compact icon for vertical bars.
- Hover tooltip and pause, right-click next, wheel navigation, and left-click chapter opening.
- Exact-source passage validation against the official BSB plain-text dataset.
- MIT license, public-domain Scripture notice, screenshot, and marketplace-ready installation and removal instructions.
